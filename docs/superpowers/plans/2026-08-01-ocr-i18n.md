# OCR + EN/ID Implementation Plan

> **For agentic workers:** Implement task-by-task in this session.

**Goal:** Ship report-photo OCR (Tesseract hybrid) and full-app EN/ID toggle.

**Architecture:** Client-only Tesseract + `parseReportText`; React `LocaleProvider` with flat dictionaries and `{var}` interpolation.

**Tech Stack:** Next.js 16, React 19, tesseract.js 5, Vitest.

## Global Constraints

- No cloud OCR API keys; photos never leave the browser.
- Default locale English; persist `pilar-locale` in localStorage.
- Manual score edit remains source of truth after OCR.
